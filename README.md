# Maksei-Works

業務系システムのアーキテクチャ設計やプロジェクト推進に長く携わりつつ、個人でのソフトウェア開発を行っています。
日々の作業の中で「ちょっと困ったこと」や興味がわいたものをソフトウェアにしています。

## 経歴
* 1994年、N88-BASICからプログラミングを開始。DirectXを用いた趣味のゲーム制作を経てWindowsソフトウェア開発へ
* 大手SIerでの大規模システム設計・プロジェクト管理、Webサービス開発に従事
* 保有資格：ITストラテジスト(ST) / プロジェクトマネージャ(PM) / データベーススペシャリスト(DB)

## プロダクト
* **HugeDiff**: (2026/10/02)
  大容量ファイルおよびディレクトリの差分比較を、ローカル環境で高速に行うためのデスクトップアプリケーション（C# / WPF）。
  [Webサイト](https://maksei-works.github.io/hugediff_web/)
